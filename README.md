# Daily Log Generator 📓

A lightweight Python CLI tool built and run entirely on Android (via Termux) that generates formatted Markdown daily logs.

## How It Works
1. Run `python log.py` in the terminal.
2. Answer 4 quick daily reflection prompts.
3. The script automatically formats the entry with timestamps and appends it to [`JOURNAL.md`](JOURNAL.md).

## Built With
* **Python 3**
* **Git & Termux (Android)**
